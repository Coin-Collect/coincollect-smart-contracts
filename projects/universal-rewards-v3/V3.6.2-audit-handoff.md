## Reproduce the release

Use clean checkouts. Local experimental batch sources are outside the release build.

```sh
npm ci --workspaces=false --ignore-scripts
stage="$(mktemp -d)"
node scripts/build-release.cjs "$stage/frozen"
node scripts/build-release.cjs "$stage/v361" 3.6.1-rc
node scripts/export-audit-sources.cjs "$stage/frozen" "$stage/v361" "$stage/review"
cmp "$stage/review/compiler-input.diff" evidence/v362-compiler-input.diff
node scripts/export-v36-abi.cjs "$stage/v361/frontend-abi.ts"
npm test --workspaces=false
COINCOLLECT_V34_FIXTURE=1 npm run --workspaces=false test:polygon-fork
npm run --workspaces=false test:polygon-fork:v36
```

The [exact compiler diff](evidence/v362-compiler-input.diff) includes compiler settings, changes to shared sources, full added and removed sources, and the four V3.6.1 overlays against their pristine tracked files. CI uploads both release manifests, full standard JSON, separately extracted compiled sources, ABIs and link/immutable references. The V3.6.1 input SHA-256 remains `8b44b0942978d7666d6694861dc80aa8a54df22aae37bec85a9ed8f38c878c7c`. The [release manifest](release-manifest-v361.json) pins the runtime templates. Linked runtime identities and immutable values are separately checked against [actual isolated fork deployments](evidence/polygon-fork-v361-97638790.json). The ledger runtime is **24,457 bytes** against the **24,576-byte** EIP-170 limit.

## Seven-contract review

| Contract | Boundary checked |
| --- | --- |
| TreasuryAssetsV36 | Separate funding, reward and swap permissions. Recheck runtime, decimals and a supported implementation. Manual review covers concealed proxies, bridge roles, freezes and token behavior changes. |
| TreasuryVaultV36 | Withdrawals and owner swaps debit only available accounting. Ledger-only allocations, recovery and spending maintain the vault equation. Native POL unwrap verifies exact deltas and aborts if the owner's transfer fails. |
| RewardRoutePlannerV36 | The approval and route index must still validate during execution. Intermediate legs and exact transfers are constrained. Allowances are cleared and checked before completion. |
| RewardSwapAdapter | Router, factory and pair identities, reserve floors, fresh observations, trade-size cap, slippage and exact in/out determine execution. The temporary router allowance must end at zero. |
| UniversalRewardsV36 | Treasury spending stays isolated by pool and reward liability. Position owner and keeper constraints apply before any payout. Exact claim deadline and recovery retain existing semantics. |
| ManagedRewardPositions | Partial ownership movements preserve accrued reward rights and total liabilities across claims, release and transfers. |
| ManagedNftCollection | Approved ERC-1155 collections must issue the configured transfer hook. Gas and pool tracking bounds protect normal collection activity. Arbitrary ERC-1155 collections lack that guarantee. |

No new critical accounting defect was demonstrated in the recheck. The existing adversarial suite covers the four exact allowance checkpoints, cross-pool isolation, unapproved paths, faulty assets, hook transfers and exact expiry.

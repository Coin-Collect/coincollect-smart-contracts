# Universal Rewards V3.10 audit handoff

Candidate for independent review. The production release decision remains open.

## Reproduce and pair the release

From this project directory, install the pinned dependencies with `npm ci --workspaces=false --ignore-scripts`.

| Release | Command argument | Committed manifest | Ledger runtime bytes |
| --- | --- | --- | ---: |
| V3.7 | `3.7.0-rc` | `release-manifest-v37.json` | 24,341 |
| V3.8 | `3.8.0-rc` | `release-manifest-v38.json` | 24,389 |
| V3.9 | `3.9.0-rc` | `release-manifest-v39.json` | 24,389 |
| V3.10 | `3.10.0-rc` | `release-manifest-v310.json` | 24,538 |

Run `node scripts/build-release.cjs <output-dir> 3.10.0-rc` and compare `manifest.json` with the committed manifest. Each release artifact bundles the exact Solidity standard input, complete ABIs, creation and runtime templates, link references and immutable references. The compiler input contains the frozen-source transformations. Review it alongside the source tree. Use the frontend CI pairing to identify the exact two Git commits and compiler-input digest.

V3.10 uses Solc 0.8.30, optimizer runs 1 and Shanghai as recorded in the build input. The EIP-170 headroom is 38 bytes. Reproduce the bytecode after any compiler, optimizer, dependency or source change. Keep the existing split into linked libraries.

## Review boundaries

- V3.7 direct reward reservation and Treasury balance identity. Review pinned paths, asset review, deposits, withdrawals, swaps and returned funding.
- V3.8 linked reward transfers and atomic ERC-721 claim/exit batches. Review batch limits, per-token transfers, position ownership, reward rounding and rollback.
- V3.9 managed ERC-1155 quantity batches. Review observation and hook ordering, release credits and mixed direct/managed pools.
- V3.10 instant creation timestamp and duration, funding variants, scheduled creation compatibility, claim windows and Treasury recovery. Review overlap of pool IDs across immutable ledgers and the frontend's registry and metadata scoping.
- Run the isolated contract suite and the V3.10 pinned Polygon fork test. Review deployed-library identities, linked templates, immutable values and matching ABI. Pinned Polygon state exercises a fork with fixture funds and a local chain ID.

## Open production gates

Independent review and remediation retest. Freeze the production address, roles, linked libraries, reviewed tokens, route policy and validated runtime hashes. Rehearse signer, Treasury, automation, monitoring and rollback operations, and verify wallet extensions and live RPC compatibility. Obtain explicit approval before merge or production deployment.
